# Smart School Management and Academic Information System (SSMS)

Welcome to the **Smart School Management and Academic Information System (SSMS)**, an AI-powered, offline-first school management system engineered for secondary schools operating in local area network (LAN) environments.

Designed specifically for **Majang Zone Secondary School, Gambella Region, Ethiopia** (Grades 9–12, 1,000–2,000 students, 20+ laboratory computers, no internet dependency).

## Technology Stack

* **Backend:** Python & Django (MVT architecture)
* **Database:** PostgreSQL (ACID compliant, relational integrity)
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5 (Bundled 100% offline)
* **Visualization:** Chart.js (Bundled 100% offline)
* **AI & Machine Learning:** Pandas, NumPy, Scikit-learn, Local Retrieval Engine
* **Deployment Target:** Windows Server / Windows 10 Host on School Local Area Network (LAN)
