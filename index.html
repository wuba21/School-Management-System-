School Management System

An AI-powered, offline-first School Management and Academic Information System designed for secondary schools operating on a local area network.

View the source repository Installation instructions

About the project

Tailored for Majang Zone Secondary School in Gambella Region, Ethiopia, the system supports grades 9–12 and is designed to operate without a cloud or internet dependency once installed on the school network.

This GitHub Pages site is an informational landing page, not the application.

The school management system is a Django application that requires a Python server and a database. GitHub Pages serves static files only, so it cannot run the Django application. To use the system, install and run it on a school computer or LAN server by following the repository’s README.

System modules

School operations

Student registration, teacher profiles, academic years, classes, sections, and subject allocations.

Teaching and learning

Timetables, attendance, examinations, mark entry, grading, and student promotion history.

Reports and insights

Role-based dashboards, school analytics, printable reports, and offline-first workflows.
